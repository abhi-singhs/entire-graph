## Part A: signatures (internal/sem/parser.go)

`signatureFromNode` (~8109) ends a signature at a `body` field or a body-like child. tree-sitter-julia keeps body statements as direct, unlabeled children, so nothing gets cut.

- Add `juliaSignature(node, src) string`, modelled on `fsharpSignature` (~4680).
- Apply it the same way the F# override is applied after entity construction (~6488), including recomputing `Fingerprint`.
- Check every Julia-gated case in the extraction switch (~5955-6060) for any path that sets `Signature` separately.

Cut rules. Confirm the node shapes by dumping the tree for a sample file rather than guessing:

- `function_definition` / `macro_definition`: end of the `signature` child. This keeps `::ReturnType` and `where {...}`, which sit inside `signature`. Expected: `function area(c::Circle)::Float64`, `function bump!(n)`, `function Base.show(io::IO, x)`, `macro trace(ex)`.
- `struct_definition`: end of `type_head`. Expected: `struct Circle <: Shape`, `mutable struct Counter`, `struct Point{T}`.
- `abstract_definition` / `primitive_definition`: keep the header whole, e.g. `abstract type A <: B end`.
- `module_definition` (including `baremodule`): end of the name. Expected: `module Shapes`.
- Short-form `assignment` (`f(x) = expr`, `f(x)::T = expr`, `f(x) where T = expr`): end of the left-hand side.
- If the expected child is missing, fall back to `signatureFromNode`.

Symbol IDs are `repo:language:path:kind:qualifiedName`; the signature is not part of them. Do NOT bump `IdentityRevision`. Prove the IDs are unchanged: collect the Julia symbol IDs from the before and after binaries on the repro and on `internal/sem/testdata`, and check the sets match.

## Part B: module DATA_FLOWS (internal/sem/provider.go)

`forEachRelation` sets `callableSymbol := !typeLikeKind(from.Kind)` (~5975). `module` is not type-like, so the DATA_FLOWS pass (~6024, which calls `returnFlowCalls` in types.go ~1052) scans a module's block. That block spans the module's member functions: the Julia `exactSymbolSource`, or the Ruby line span.

- Skip DATA_FLOWS when `from.Kind == "module"`, for every language. No language can `return` from a module body. Also make sure no DATA_FLOWS record has a module `to_id` through another producer.
- Keep the change local to the DATA_FLOWS gate. Do not change `callableSymbol` itself: it also gates ASYNC_CALLS (~5984) and the HTTP scan (~6176). List those in the PR as a follow-up.
